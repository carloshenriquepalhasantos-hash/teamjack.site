## 📌 Sobre o Projeto
O **TeamJack** é uma Landing Page institucional e de conversão desenvolvida sob medida para o treinador Jackson Freitas. O projeto foi arquitetado com foco em **experiência do usuário (UX/UI)**, apresentando uma estética moderna em *Dark Mode*, identidade visual marcante com detalhes em roxo neon, e uma estrutura fluida voltada para conversão de leads via WhatsApp.

---

## 💡 Principais Diferenciais e Funcionalidades
* **Design System Personalizado:** Interface moderna com tema escuro profundo (`#0b0813`), efeitos visuais de *glow*, sombras direcionais e hierarquia visual refinada.
* **Hero Section Imersiva:** Estruturação avançada em múltiplas camadas (Z-index) combinando fotografia de fundo, recorte de personagem em destaque e tipografia de alto impacto.
* **Componentes Interativos em JavaScript Puro:** Carrossel dinâmico de resultados de alunos com suporte a toque (*touch/swipe*) para dispositivos móveis e navegação por indicadores.
* **Responsividade Extrema:** Layout totalmente fluido e adaptado para qualquer resolução (smartphones, tablets e desktops) utilizando utilitários avançados do **Tailwind CSS**.
* **Integração Direta com Canais de Atendimento:** Botões de CTA dinâmicos e flutuantes conectados diretamente à API oficial do WhatsApp com mensagens pré-formatadas para fechamento de planos.

---

## 🛠️ Tecnologias Utilizadas
Este projeto foi construído utilizando tecnologias modernas de desenvolvimento front-end sem dependências complexas de frameworks pesados, garantindo carregamento instantâneo:

* **HTML5 Semantic:** Estruturação limpa e otimizada para SEO.
* **Tailwind CSS (CDN):** Estilização ágil e responsiva baseada em classes utilitárias.
* **JavaScript (ES6+):** Lógica interativa para o carrossel de imagens, menu mobile e efeitos de rolagem (*Scroll Reveal*).
* **Lucide Icons:** Iconografia vetorial moderna e minimalista.
* **Google Fonts (Plus Jakarta Sans):** Tipografia limpa e de alta legibilidade.
