# TEAMJACK

Site de apresentação da consultoria de Jackson Freitas, com informações sobre o acompanhamento, planos e contato pelo WhatsApp.

## Executar

Abra `index.html` em um navegador moderno ou sirva a pasta com um servidor HTTP estático. O site usa HTML, CSS e JavaScript puros, sem instalação de dependências.

## Estrutura

```text
index.html          Estrutura e conteúdo da página
styles/site.css     Estilos e layout responsivo
scripts/site.js     Menu, navegação por capítulos e efeitos
assets/images/      Imagens utilizadas e arquivos de imagem adicionais
```

O site mantém imagens antigas na raiz e em `assets/images/` para preservar os arquivos do repositório. As imagens atualmente exibidas são referenciadas em `index.html`.

## Manutenção

- Atualize os links de WhatsApp, informações e valores em `index.html`.
- Confira os serviços e condições antes de publicar mudanças.
- Utilize imagens com autorização para publicação, especialmente quando outras pessoas aparecem nas fotos.
- A navegação respeita a preferência do navegador por movimento reduzido.
